surface-scan

A defensive external attack-surface inventory. Point it at the DNS records we own; it tells us what's live, what's in front of it, and what each host runs — so when the next critical advisory lands, we answer "are we exposed, and where?" in seconds.

Python 3.10+ MIT licensed DNS · Liveness · CDN/WAF · Fingerprint YAML-driven No exploitation

The problem

A CVE drops. Now what?

The first question every time is the same — and answering it by hand across hundreds of hostnames is slow and error-prone.

Recent examples
  • PHP2Shell — CVE-2026-109618 / 109619, CVSS 9.2, exploited in the wild within a day
  • Node.js Brotli — CVE-2026-111497, CVSS 9.8, OOB write
  • …and whatever lands next — a framework, a web server, a CMS
What we need
  • Inventory once — DNS, liveness, edge, stack
  • Correlate any advisory against what we already know
  • Repeatable — not a one-off script per CVE
  • Honest — "likely, confirm" beats a false "clean"
Design stance: presence first, version when visible. The default question is "is this technology in use here?" — answerable even when the version is hidden.

Module · models.py + inputs.py

Data model & input loading

models.py
DetectionOne tech found: name, category, version, confidence, evidence.
HostResultEverything known about a host: DNS, edge, liveness, TLS, detections, verdicts.
.tech_by_category()Detections in one category.
.to_dict()JSON-serialisable form.
inputs.py
load_records()Dispatch by extension → list of HostResult.
_rows_to_hosts()Header detection, column mapping, validation, de-dup.
_clean_host()Strip scheme/path/port, lower-case.
_pick()Find a column by accepted names.

Accepts flexible columns — minimum is a hostname. hostname,type,target is the happy path.

Module · dns_probe.py + doh.py

DNS resolution (with DoH fallback)

dns_probe.py
resolve_host()Main entry. Modes: udp, doh, auto (UDP then DoH fallback). Fills A/AAAA/CNAME chain/MX/TXT/NS/CAA.
_follow_cname()Walk the CNAME chain; detect dangling targets.
_query()Single record lookup; exceptions swallowed.
_finish_dns()Hygiene flags: dangling CNAME, private IP in public DNS, dns_fail.
doh.py — DohResolver
query()Record values over HTTPS (RFC 8484 JSON). Works where UDP:53 is blocked.
has_cname() · resolves()Chain-following helpers for the DoH path.
Why DoH matters: locked-down networks and proxied egress often block UDP:53. The tool still resolves over HTTPS.

Module · http_probe.py

Liveness, HTTP & TLS

probe_http()Main entry. TCP-checks web ports, HTTPS-first GET (HTTP fallback), captures status, redirect chain, title, headers, cookies, timing; reads TLS.
check_ports() · tcp_open()Which ports accept a connection. Admin/DB ports only on direct hosts, opt-in.
_tls_info()Certificate issuer + expiry, with near-expiry / expired notes.
_looks_like_waf_block()Classify a 403/429/503 challenge as waf_blocked, not a real app error.
_fetch_fingerprint_paths()GET a few benign public paths for stronger fingerprinting (no payloads).

Default web ports: 443, 80, 8443, 8080, 8000, 3000, 5000, 9000. Extra (opt-in, direct only): 22, 3389, 3306, 5432, 6379, 27017, …

Module · cdn.py + classify.py

Edge detection & classification

cdn.py — CdnMatcher
detect()Combine all signals by weighted vote → provider / none / unknown + confidence.
by_cname()Provider by CNAME suffix.
by_headers()Provider by header / cookie.
by_ip()Provider by IP-range membership.
classify.py
classify()Label each host.
  • own-infra — our IPs / CDN → in scope
  • third-party-saas — Zendesk, HubSpot… → recorded, not probed
  • suspicious — dangling / private IP

Auto-detected across Cloudflare, Akamai, Fastly, CloudFront, Azure Front Door, Imperva, Sucuri, F5, AWS ALB. Override IP ranges with signatures/cdn_ranges.json.

Module · fingerprint.py

The signature engine

Functions
Fingerprinter.run()Evaluate every signature; capture versions; apply implies; sort by category.
Signature.match()Match headers, server, cookies, HTML, paths → Detection with evidence.
Signals (any match wins)
  • headers — e.g. X-Powered-By
  • cookies — e.g. laravel_session
  • html — body markers
  • paths — path + status + body
  • version — (?P<version>…) group
  • implies — Laravel ⇒ PHP

Add a technology — no code

# signatures/custom.yaml
"My Framework":
  category: backend
  confidence: high
  headers:
    X-Powered-By: "MyFramework"
  implies: ["Node.js"]

Frontend ≠ backend: Angular/React/Vue are reported in their own category — "Angular found" is never misread as "Node found".

Module · advisories.py

Advisory correlation

Map a CVE to a technology + version ranges. Version/inventory logic only — never exploitation.

Verdict logic — Advisory.evaluate()
VerdictWhen
affectedtech present and version in range
likelypresent, version unknown, exposure hint met
possiblepresent, version not observable
not-detectednot seen / version out of range
unknownblocked / unreachable
A profile is one YAML file
id: PHP2SHELL-2026
tech: PHP
affected:
  - ">=8.3.0,<8.3.36"
  - ">=8.2.0,<8.2.35"
  - "<8.2.0"
action: "Upgrade + restart FPM"
Honesty by design: most runtimes (Node.js especially) don't expose a version over HTTP, so verdicts are often possible/likely → confirm with owner. The tool never fakes a yes/no.

In practice

The emergency workflow

# 1 · Inventory everything → Excel + JSON in ./output/
python scan.py --input records.csv

# 2 · A PHP CVE drops. Triage against the last run —
#     NO new traffic is sent.
python scan.py --from-last-run --advisory php2shell

# 3 · Find every host running a given stack
python scan.py --input records.csv --tech nodejs,angular,wordpress

# 4 · Restricted network? Resolve over HTTPS
python scan.py --input records.csv --dns-mode doh
The payoff: 200 hostnames become a short list of the handful that need a human — in seconds.

Scope & honesty

Guardrails & limits

Safety boundaries
  • No exploitation, no WAF bypass, no payloads
  • nuclei limited to detection tags
  • SaaS targets recorded, not probed
  • Per-host rate limiting (--rps)
  • Authorised assets only · SOC informed
Honest limits
  • WAF / expose_php=Off can hide signals
  • Most runtimes hide their version over HTTP
  • Verdicts lean possible/likely, by design
  • Run from a cloud VM, not an allowlisted office IP
Pair it with internal inventory — osquery, image scanning (Trivy/Grype), dependency manifests — for authoritative version data. External + internal = the full picture.
